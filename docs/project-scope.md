## Project Purpose

The **Warehouse Order and Inventory Management Portal** is a full-stack web application designed to help a warehouse admin:

- Manage products
- Track inventory levels
- Create customer orders
- Monitor low-stock items
- View key warehouse activity through a simple dashboard
The **Warehouse Order and Inventory Management Portal** is a full-stack web application designed to help a warehouse admin:

- Manage products
- Track inventory levels
- Create customer orders

This project is **not intended to be a large enterprise warehouse system**.  
The goal is to build a realistic, clean, and resume-ready full-stack project that demonstrates:

- **Spring Boot backend development**
- **Angular frontend development**
- **REST API design**
